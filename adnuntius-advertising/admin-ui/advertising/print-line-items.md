# Print Line Items

To generate a QR code, go to [https://admin.adnuntius.com/print-line-items](https://admin.adnuntius.com/print-line-items) and click "new" in the upper right corner.&#x20;

<figure><img src="../../../.gitbook/assets/Print LI.png" alt=""><figcaption></figcaption></figure>

Give the line item a name and description (optional) of your choice, and set a start and end date. These details will be available on the political campaign's transparency notice.&#x20;

Select an Advertiser from [the ones you have created here](https://docs.adnuntius.com/political-ads/how-to-book-a-political-campaign#id-1-create-an-a-dvertiser). When you next select an election and election topic, these are fetched from the advertiser you chose. [See here for more information](https://docs.adnuntius.com/political-ads/how-to-book-a-political-campaign#id-1-create-an-a-dvertiser) on Advertisers and political campaign budgets.
